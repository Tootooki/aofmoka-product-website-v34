# AOFMOKA Product Website V34

V34 preserves the approved V32 storefront and replaces the separate product-size popup and chat with one centered AOFMOKA living control.

- Closed state: circular black launcher with the original colorful AOF emblem.
- Product state: the Amazon badge plus four equal actions—Medium, Large, XLARGE, and Chat.
- Chat state: animated AOFMOKA conversation, quick help topics, automatic replies, free-text entry, and a secure email handoff.
- Initial state: a small animated `new drops?` invitation comes from the same control.
- Mobile and desktop: the module opens above the same centered launcher and closes smoothly back into it.

The site keeps the mirrored sticky-header fade, same-tab Amazon navigation, exact tracked child ASINs, Font 4 everywhere, two-column mobile products, and the selected product-name bean.
